# Rounak Das — project repositories

Each project has its own repository. The six tools formerly stored inside Evidence Check were separated on 21 November 2026. Their previous demo paths forward to the standalone sites.

| Project | Repository | Scope |
|---|---|---|
| Cancer Clock | [cancer-clock](https://github.com/rounakdas07/cancer-clock) | NHS cancer backlog forecasting |
| Breath Yield | [breath-yield](https://github.com/rounakdas07/breath-yield) | Breath-testing study planning |
| Amendment Replay | [amendment-replay](https://github.com/rounakdas07/amendment-replay) | Clinical-trial amendment checks |
| Signal to Scan | [signal-to-scan](https://github.com/rounakdas07/signal-to-scan) | Imaging research tool |
| Tumour Reach | [tumour-reach](https://github.com/rounakdas07/tumour-reach) | Oncology evidence tool |
| Pilot Case | [pilot-case](https://github.com/rounakdas07/pilot-case) | NHS pilot cost planning |
| After MRI | [after-mri](https://github.com/rounakdas07/after-mri) | Prostate diagnostic pathway tool |
| Vaccine Brief | [vaccine-brief](https://github.com/rounakdas07/vaccine-brief) | Vaccine research brief |
| Evidence Check | [evidence-check](https://github.com/rounakdas07/evidence-check) | Evidence-checking benchmark |
| Cancer Dataset Finder | [cancer-datasets](https://github.com/rounakdas07/cancer-datasets) | Public cancer research datasets |
| Care Search | [care-search](https://github.com/rounakdas07/care-search) | UK care-provider search and shortlist |

| Frontier Booking Workbench | [frontier-booking-workbench](https://github.com/rounakdas07/frontier-booking-workbench) | NHS booking workload finder and pilot proposals |
| Day Check | [day-check](https://github.com/rounakdas07/day-check) | Prototype with synthetic example data |

Day Check is a prototype and should not be represented as a validated production tool. Revisions and generated build folders are not counted as additional projects.
