# Explain Evidence Check in one minute

“I made a small oncology test set for checking whether AI claims go beyond their evidence. Each case has a source-linked evidence summary, a candidate claim and a reference answer with a reason. You can try a case yourself or run the set through a model and export its disagreements.”

## Demonstrate it

1. Open the page. Explain the denominator example shown beside the headline.
2. Open **Explore the checks**. Select a verdict, then inspect the reference explanation and paper link.
3. Switch to **Test model outputs**. Load the **scripted example**, score it, and show the disagreements. Say explicitly that these are constructed predictions, not an actual AI model run.
4. Export the report. It keeps source links, rationales, missing cases, suite version and the demo label.

## Why it relates to Sable

Sable has published work on linking evidence observations to sources and classifying directional relationships. This pack is a small additional research contribution for discussion. It is not an audit of Sable and does not replace its existing benchmark.

## Be candid if asked

- “I used AI to help build the app and prepare the cases. I can explain the source selection, label rules and scoring.”
- “The current answers are draft references; independent scientific adjudication would be the next step.”
- “This tests labels against a curated summary, not whether a model can read and extract an entire paper.”
- “The useful contribution I could make part-time is expanding source-grounded cases, reviewing annotations and analysing errors under supervision.”

Do not claim measured time savings, model performance, clinical validation, or an existing partnership.
